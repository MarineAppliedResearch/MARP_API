What MARP changes

The same stages, no longer standing in line.

Most of the months go into the gaps between stages, where review waits on processing and analysis waits on review. None of that work disappears in MARP. Every stage stays attached to the same record, so a stage can start on what is ready rather than waiting for the one before it to finish everything.

One stage at a time

  1. Collect
  2. Ingest and align
  3. Detect
  4. Expert review
  5. Analyse and report

Each stage starts when the one before it ends.
